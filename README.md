# Web-Bootstrap

Dengan mengacu pada layout di Latihan Web 03, buatlah website portofolio dengan komponen dan tema sesuai kreativitas Anda.
Portofolio bisa ditujukan untuk pribadi, komunitas, perusahaan, atau ide lainnya.

Hal yang harus diperhatikan dalam metode pengembangan:

- Pengembangan memanfaatkan repository GitHub
- Buatlah repository publik dalam akun GitHub untuk pengembangan web portofolio ini
- Branch main digunakan sebagai branch utama dan final
- Untuk latihan tahap ini, buat branch dengan nama Web-Bootstrap

Hal yang harus diperhatikan membuat web:

- Layout one page seperti pada Latihan Web 03
- Menggunakan Bootstrap sepenuhnya
- Tampilan responsif
- Minimal ada 3 section utama dengan setidaknya 2 section akan dihubungkan dengan database
- Buat sekreatif mungkin dengan aset yang dikreasi sendiri atau aset yang lisensinya bebas

!!! Yang harus disubmit:

- Zip keseluruhan web dan informasi repositori dalam file dengan nama repo.txt di folder utama/root.
